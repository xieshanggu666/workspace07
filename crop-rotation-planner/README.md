# 社区菜园轮作规划工具

零依赖单文件网页应用，用浏览器打开 `index.html` 即可使用。数据保存在浏览器 localStorage，可导出 JSON 备份 / 导入恢复。

## 使用流程（对应页面 ① → ④）

1. **种植区绘制**：勾选「绘制模式」在网格上拖出种植区（1 格 = 1m²），点击区域编辑名称、日照（全日照/半日照/荫蔽）、土壤（壤土/沙壤土/沙土/黏土）。相邻关系由地块位置自动判定。
2. **历史种植记录**：登记每个区往年种过的作物、施肥方式、病虫害程度与种类，作为轮作判断依据。
3. **下一季种植计划**：选区、选作物、定播种日期，系统自动：
   - 推算 **育苗 → 移栽 → 采收** 各阶段日期（直播作物无移栽阶段）；
   - 规则检查：同科连作、前茬适宜/禁忌、病虫害复发风险、日照与土壤匹配、相邻作物禁忌、同区时间冲突；
   - 对提醒/冲突可 **登记例外原因** 留档；
   - 遇天气变化、人员不足可整体平移日期并记录调整日志。
4. **成果输出**：分区种植图、按 ISO 周汇总的每周田间任务（整地/育苗/移栽/管理/采收）、含采购截止日期的种子采购清单。可直接打印。

## 规则与数据说明

- 内置 20 种常见蔬菜的科属、各阶段天数、日照/土壤要求、经验用种量、宜忌前茬与忌邻作物（见 `index.html` 中 `CROPS` 表），可按本地品种修改。
- 用种量 = 面积 × 经验值 × 1.15 损耗系数；采购截止 = 最早播期前 14 天。
- 点击页首「载入示例数据」可快速体验完整流程（示例中 B 区西葫芦会触发连作提醒）。
